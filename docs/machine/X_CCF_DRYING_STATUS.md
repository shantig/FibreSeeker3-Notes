# X-CCF Drying Status

## Status: UNANSWERED

Question: **Should FibreSeek X-CCF be actively heated/dried, and if so under what conditions?**

## FibreSeek evidence

- **FACT (FS-120):** for long-term storage, the FibreSeeker 3 User Manual R1
  instructs users to remove materials and store them in a sealed container.
- **FACT (FS-120):** the manual says highly hygroscopic materials should be dried
  before each print and gives PETG, PC, and PACF as examples.
- **FACT (FS-120):** the same manual describes X-CCF as continuous carbon fiber
  impregnated with thermoset resin, but does not identify X-CCF as hygroscopic
  or provide a heated-drying instruction.
- **FACT (FS-101–FS-115, FS-120, FS-125, FS-130–FS-149):** no inspected
  FibreSeek page, store record, manual, support SOP, or current Rocket preset
  provides an X-CCF dryer temperature, duration, permission, or prohibition.
- **FACT (FS-125):** composite `TemperaturePreheat` data belongs to print/nozzle
  processing; it is not documented as a spool-drying condition.

## Conclusion

There is no first-party basis in the preserved Phase 1A corpus to recommend
heated drying of X-CCF or to state that heating is prohibited. Keep X-CCF sealed
for long storage as the manual directs, and request material-specific guidance
from FibreSeek before applying heat.

No Anisoprint CCF guidance was substituted for FibreSeek evidence.
