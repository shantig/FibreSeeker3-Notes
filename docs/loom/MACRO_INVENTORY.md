# Loom Macro Inventory

## Scope

LM-005 preserves 122 loaded `gcode_macro` names and their exact bodies. This
file is a passive name inventory. The lexical categories below overlap and do
not assert behavior. Body-supported findings for selected macros are recorded
separately in `CONFIGURATION_DISCOVERY.md`. No macro was invoked.

## Lexical categories

| Name terms | Matching names | Interpretation limit |
|---|---:|---|
| fiber/fibre, extruder, load/unload, filament | 22 | Material/tool vocabulary only |
| M280, servo, cut | 3 | Actuator/cut vocabulary only |
| clean, brush, waste, cooling, preload | 26 | Cleaning/station vocabulary only |
| calibration, align, offset, homing, mesh, probe, shaper, PID | 28 | Calibration vocabulary only |
| fan, temperature, standby, idle | 10 | Thermal/idle vocabulary only |
| print, pause, resume, cancel, timelapse, SD-card, hyperlapse | 21 | Print-lifecycle vocabulary only |
| explicit test names | 7 | Test label only |

Counts are non-exclusive: one name may appear in multiple rows.
